# FelipeChavesWeb.github.io

Portfolio site for Felipe Chaves.

## GitHub Pages
This repository is designed to be published as the account's User Page:

- Portfolio: `https://felipechavesweb.github.io/`
- Stillgrove concept: `https://felipechavesweb.github.io/stillgrove/`

## Upload
Upload the contents of this folder to the **root** of the `FelipeChavesWeb.github.io` repository and commit to `main`.

Expected root files/folders:

- `index.html`
- `styles.css`
- `favicon.svg`
- `stillgrove/`

The Athriun and Zuccä cards currently link to their existing GitHub Pages projects on the `oggfelpz` account.

## Language behavior

The portfolio now supports English and Brazilian Portuguese.

Priority:
1. `?lang=en` or `?lang=pt`
2. saved visitor preference
3. browser language
4. English fallback

Examples:
- `https://felipechavesweb.github.io/?lang=en`
- `https://felipechavesweb.github.io/?lang=pt`

Visitors can also switch languages with the `PT / EN` control in the header.
